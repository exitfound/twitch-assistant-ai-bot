Граф структуры бота

Доступ, лимиты и паузы бота по статусу зрителя. В центре – выбранный статус, от него расходятся разделы, на концах ветвей – отдельные функции со значением для этого статуса. Статусы упорядочены по возрастанию: чем выше статус, тем больше лимиты и короче паузы.

Описание функции – при наведении курсора. Нажатие закрепляет окно до клика по пустому месту или по другой функции.
